# Glossary — AI Daily Telegram Bot: Shared Vocabulary

| Field | Value |
| --- | --- |
| Version | v0.1 |
| Last Updated | 2026-08-06 |
| Owner | Tech Writer |
| Status | In Review |

---

| Term | Definition |
| --- | --- |
| Digest / brief | The formatted daily AI news message |
| Scraper | Module fetching items from one or more sources |
| Source | A feed/site scraped (GitHub Trending, arXiv, RSS, X, India outlets) |
| Fallback | Curated content served when live sources fail |
| Cache | diskcache store of recent items |
| Broadcast | Scheduled digest delivery |
| Split | Breaking an oversize message into ≤4096-char parts |
| Command | Telegram slash-command (e.g., `/daily`) |
| Summarizer | Gemini-based article condensation |
| Feed | RSS/Atom stream consumed by feedparser |
